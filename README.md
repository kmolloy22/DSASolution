# DSASolution

A .NET solution of data structures and algorithms practice problems in C#. Each problem has its own project, and most have a matching NUnit test project.

Problems are based on the [dotnet_interview_questions](https://github.com/StefanTheCode/dotnet_interview_questions) study guide.

## Contents

- [Arrays](#arrays)
- [Strings](#strings)
- [Linked Lists](#linked-lists)
- [Stacks](#stacks)
- [Queues](#queues)
